# Résumé bullets

Use the bullets that match work you can explain and demonstrate:

- Engineered a full-stack hospital ERP using React, TypeScript, Java 21,
  Spring Boot, PostgreSQL, and Redis across patient, appointment, admission,
  pharmacy, laboratory, billing, and audit workflows.
- Designed race-safe pharmacy billing with PostgreSQL row/advisory locks,
  idempotency keys, database constraints, and `BigDecimal` money calculations.
- Implemented stateless JWT authentication and role-based authorization with
  secure password hashing, strict validation, CORS controls, request tracing,
  rate limiting, and structured error handling.
- Built a production delivery path with Flyway migrations, non-root multi-stage
  containers, Kubernetes autoscaling and disruption controls, CI, CodeQL,
  dependency automation, Testcontainers, Prometheus, Grafana, and k6.
- Created a responsive clinical dashboard that supports secure login and live
  operational data while retaining a standalone portfolio demo mode.

## Add metrics only after measuring

Replace placeholders with reproducible evidence:

- sustained `[N]` requests/second at p95 `[X]` ms on `[environment]`
- prevented overselling in `[N]` concurrent billing attempts
- achieved `[X]%` line/branch coverage on `[commit SHA]`
- reduced container size from `[A]` MB to `[B]` MB
- restored a `[size]` database backup within `[time]`

Do not call the project “HIPAA compliant,” “FAANG-level,” or “production proven”
without an independent review and real operational evidence. In interviews,
lead with the concurrency design, security tradeoffs, failure modes, and test
strategy.
